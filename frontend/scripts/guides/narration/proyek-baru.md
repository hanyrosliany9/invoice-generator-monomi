# Narasi / Narration: Proyek: buat dan kelola

Video: `proyek-baru.50acddac.mp4` (1280x820, 01:45.4, silent). Guide slug: `proyek-baru`.

Timestamps are mm:ss.s in the video. Each step has a window (from when the step starts until the next one starts) and a word budget at a calm speaking pace
(Indonesian about 2.4 words/second, English about 2.6). The drafts are written to fit; shorten them or leave pauses rather than speed up.
The orange highlight and numbered badge appear a few seconds into each step, so name the thing the badge points at when it shows.

Pembukaan (opsional, sebelum 00:00) / Opening (optional, before 00:00):

- ID: Buat proyek untuk klien dengan jenis, tanggal, daftar produk dan estimasi biaya, lalu ubah statusnya dan buka Production Hub.
- EN: Create a project for a client with type, dates, product list and cost estimate, then change its status and open the Production Hub.

## Langkah 1 / Step 1: Buka menu Proyek

- Window: 00:00.0 - 00:09.3 (9.3 s)
- ID (20 of max 21 words): Buka menu Proyek. Semua proyek ada di sini. Klik Proyek Baru untuk membuat, atau cari proyek lama lewat kolom pencarian.
- EN (23 of max 23 words): Open the Proyek menu. All projects are here. Click Proyek Baru to create one, or find an old project with the search box.
- Tip (opsional / optional, only if there is time): Proyek harus ada sebelum Anda membuat penawaran atau invoice, karena keduanya selalu terkait ke satu proyek. / A project must exist before you create a quotation or invoice, because both are always linked to one project.

## Langkah 2 / Step 2: Isi deskripsi dan output

- Window: 00:09.3 - 00:25.8 (16.5 s)
- ID (30 of max 38 words): Isi deskripsi dan output. Tulis Deskripsi Proyek secara singkat, lalu Output yaitu hasil akhir yang dijanjikan, misalnya Video 30 detik. Lingkup Pekerjaan boleh diisi untuk merinci tugas dan jumlah revisi.
- EN (23 of max 41 words): Fill in description and output. Write a short Deskripsi Proyek, then the Output, the final deliverable you promised, for example Video 30 detik.
- Tip (opsional / optional, only if there is time): Deskripsi dan lingkup ikut tercetak di penawaran dan invoice, jadi tulis dengan bahasa yang jelas bagi klien. / The description and scope are printed on quotations and invoices, so write them clearly for the client.

## Langkah 3 / Step 3: Pilih klien dan jenis proyek

- Window: 00:25.8 - 00:48.7 (22.9 s)
- ID (31 of max 53 words): Pilih klien dan jenis proyek. Pilih Klien dari daftar; ketik untuk mencari. Pilih Jenis Proyek: jenis ini menentukan awalan nomor proyek. Atur juga tanggal mulai dan tanggal selesai di bagian Tanggal.
- EN (26 of max 58 words): Choose the client and project type. Pick the Klien from the list; type to search. Choose the Jenis Proyek: the type decides the project number prefix.
- Tip (opsional / optional, only if there is time): Klien belum ada? Tambahkan dulu lewat panduan Klien. / Client not there yet? Add it first with the Clients guide.

## Langkah 4 / Step 4: Isi produk dan layanan

- Window: 00:48.7 - 01:04.0 (15.3 s)
- ID (30 of max 35 words): Isi produk dan layanan. Setiap baris adalah satu hal yang ditagihkan: nama item, deskripsi singkat, Jml, dan Harga. Klik Tambah Baris untuk item berikutnya. Total Estimasi di bawahnya dihitung otomatis.
- EN (31 of max 38 words): Enter products and services. Each row is one billable item: item name, short description, Jml and Harga. Click Tambah Baris for the next item. The Total Estimasi below is calculated automatically.
- Tip (opsional / optional, only if there is time): Baris ini dipakai kembali saat Anda membuat penawaran, jadi isi harga dengan benar. / These rows are reused when you create a quotation, so enter prices carefully.

## Langkah 5 / Step 5: Isi estimasi anggaran biaya

- Window: 01:04.0 - 01:19.2 (15.2 s)
- ID (30 of max 35 words): Isi estimasi anggaran biaya. Klik Tambah Baris Biaya untuk memperkirakan biaya produksi: pilih Kategori Biaya, Tipe Biaya Langsung atau Tidak Langsung, dan Estimasi Biaya. Dari sini aplikasi memperkirakan margin proyek.
- EN (27 of max 38 words): Enter the cost estimate. Click Tambah Baris Biaya to estimate production cost: choose a Kategori Biaya, the Tipe Biaya Langsung or Tidak Langsung, and the Estimasi Biaya.
- Tip (opsional / optional, only if there is time): Bagian ini opsional dan hanya untuk perhitungan internal; klien tidak melihatnya. / This section is optional and internal only; the client does not see it.

## Langkah 6 / Step 6: Simpan dan lihat halaman proyek

- Window: 01:19.2 - 01:29.3 (10.1 s)
- ID (17 of max 23 words): Simpan dan lihat halaman proyek. Setelah disimpan, halaman proyek menampilkan statusnya, tombol Pusat Produksi, dan tombol Edit.
- EN (24 of max 25 words): Save and view the project page. After saving, the project page shows the status, the Pusat Produksi (Production Hub) button and the Edit button.

## Langkah 7 / Step 7: Ubah status proyek

- Window: 01:29.3 - 01:36.4 (7.1 s)
- ID (14 of max 15 words): Ubah status proyek. Buka menu Tindakan lainnya dan pilih Mulai Proyek saat pekerjaan dimulai.
- EN (16 of max 17 words): Change the project status. Open the Tindakan lainnya menu and choose Mulai Proyek when work starts.

## Langkah 8 / Step 8: Buka Pusat Produksi

- Window: 01:36.4 - 01:45.4 (9.0 s)
- ID (17 of max 20 words): Buka Pusat Produksi. Pusat Produksi mengumpulkan call sheet, jadwal, shot list, deck, dan ruang media proyek ini.
- EN (21 of max 22 words): Open the Production Hub. The Production Hub (Pusat Produksi) gathers this project's call sheets, schedules, shot lists, decks and media spaces.
