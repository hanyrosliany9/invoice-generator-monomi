# Narasi / Narration: Pintasan Keyboard

Video: `pintasan-keyboard.552e4180.mp4` (1280x800, 00:42.3, silent). Guide slug: `pintasan-keyboard`.

Timestamps are mm:ss.s in the video. Each step has a window (from when the step starts until the next one starts) and a word budget at a calm speaking pace
(Indonesian about 2.4 words/second, English about 2.6). The drafts are written to fit; shorten them or leave pauses rather than speed up.
The orange highlight and numbered badge appear a few seconds into each step, so name the thing the badge points at when it shows.

Pembukaan (opsional, sebelum 00:00) / Opening (optional, before 00:00):

- ID: Bekerja lebih cepat tanpa mouse. Semua pintasan di Monomi dalam satu tempat, untuk Windows dan Mac.
- EN: Work faster without the mouse. Every shortcut in Monomi in one place, for Windows and Mac.

## Langkah 1 / Step 1: Tekan ? di mana saja

- Window: 00:00.0 - 00:10.8 (10.8 s)
- ID (28 of max 24 words) (OVER BUDGET: trim a few words): Tekan ? di mana saja. Tekan ? (Shift + /) di halaman mana pun untuk melihat pintasan halaman itu lebih dulu, lalu pintasan yang berlaku di mana saja.
- EN (23 of max 26 words): Press ? anywhere. Press ? (Shift + /) on any page to see that page's shortcuts first, then the ones that work everywhere.
- Tip (opsional / optional, only if there is time): Di Mac, tombol tampil sebagai ⌘ (Command), ⌥ (Option) dan ⇧ (Shift). Ctrl+K (⌘K) membuka halaman mana pun dan Ctrl+B (⌘B) menciutkan sidebar. / On a Mac the keys appear as ⌘ (Command), ⌥ (Option) and ⇧ (Shift). Ctrl+K (⌘K) jumps to any page and Ctrl+B (⌘B) collapses the sidebar.

## Langkah 2 / Step 2: Foto dan video

- Window: 00:10.8 - 00:24.0 (13.2 s)
- ID (14 of max 30 words): Foto dan video. Arahkan kursor ke tombol di penampil foto untuk melihat tombol pintasannya.
- EN (32 of max 33 words): Photos and videos. Hover a button in the photo viewer to see its key. ← → move between photos, + and − zoom, 0 resets the zoom, R rotates and Esc closes.
- Tip (opsional / optional, only if there is time): Shift+klik kotak centang kedua di galeri untuk memilih semua foto di antaranya. / Shift+click a second checkbox in the gallery to select every photo in between.

## Langkah 3 / Step 3: Editor deck

- Window: 00:24.0 - 00:29.9 (5.8 s)
- ID (8 of max 13 words): Editor deck. Editor deck bekerja seperti aplikasi desain.
- EN (10 of max 14 words): Deck editor. The deck editor works like a design tool.
- Tip (opsional / optional, only if there is time): Tombol satu huruf seperti R, C, T dan L hanya bekerja saat Anda tidak sedang mengetik di kotak teks. / Single-letter keys such as R, C, T and L only work when you are not typing in a text box.

## Langkah 4 / Step 4: Mempresentasikan deck

- Window: 00:29.9 - 00:42.3 (12.5 s)
- ID (23 of max 28 words): Mempresentasikan deck. Klik Presentasi, lalu pakai → atau Space untuk slide berikutnya dan ← untuk sebelumnya. Ketik nomor slide lalu Enter untuk melompat.
- EN (30 of max 31 words): Presenting a deck. Click Present, then use → or Space for the next slide and ← for the previous one. Type a slide number and press Enter to jump there.
- Tip (opsional / optional, only if there is time): Orang yang melihat deck lewat tautan bagikan juga bisa memakai tombol panah. / People viewing a shared deck can use the arrow keys too.
