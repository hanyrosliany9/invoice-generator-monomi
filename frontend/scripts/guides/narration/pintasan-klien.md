## Langkah 2 / Step 2: Penampil foto

- Window: 00:13.4 - 00:27.3 (13.9 s)
- ID (32 of max 32 words): Penampil foto. Buka sebuah foto, lalu pakai ← dan → untuk pindah antar foto, + dan − untuk memperbesar atau memperkecil, 0 untuk me-reset zoom, R untuk memutar dan Esc untuk menutup.
- EN (31 of max 35 words): Photo viewer. Open a photo, then use ← and → to move between photos, + and − to zoom, 0 to reset the zoom, R to rotate and Esc to close.
- Tip (opsional / optional, only if there is time): Saat foto diperbesar, tombol panah tidak lagi berpindah foto. / While the photo is zoomed in, the arrow keys no longer change photos.
